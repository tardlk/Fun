# 海量采集聚合（旧版 TVBox JS）

脚本：[`js/collect.js`](../js/collect.js)，版本 `1.0.0`。

从 `tardlk/OmniBox-Spider/影视/采集/海量采集聚合.js` 收录的 162 个候选地址出发，合并 Fun 原有的 36 个独立采集接口。规范化末尾斜线、`/at/json/` 后缀并按地址去重，最终保留 **176 个不同接口地址**；不同域名、线路路径和固定类型参数仍作为独立接口保留。原聚合脚本未收录的地址不在这次合并范围内。

`tvbox.json`、`vod.json` 各移除 36 个 `type=0/1` 采集站，加入一个 `type=3` 的“海量采集聚合”。影探、爱电影、看剧等其它爬虫源以及直播配置保留。

## 使用

刷新 TVBox 配置后重启应用，选择“海量采集聚合”。分类栏按来源浏览，“类型”筛选对应来源的分类。首页从前三个优先来源依次取推荐，任意一个有结果即返回。

搜索汇总不同来源，备注显示来源名。同一来源同一影片去重，不把不同来源的同名影片合成一部，以免年份、季数或版本不同导致错误匹配。详情和分集标识均包含来源；读取详情时精确核对影片 ID，避免接口忽略 `ids` 后误播其它影片。线路内重复地址去重，明确的媒体直链线路优先展示。

所有候选地址均可从分类进入，包括此次检测未响应的地址。2026-11-13 的一次检测中，79 个接口返回标准采集数据；排序优先使用本次成功的接口，再考虑 Fun 原有接口和历史可用状态。检测只代表当前测试网络，地址未响应不等于永久失效。

## 搜索耗时与旧宿主兼容

默认使用同步 `req`。目标 `q215613905/TVBoxOS` 的旧实现把异步网络回调投递到同一个 JS 执行线程，等待 Promise 时可能阻塞该回调，因此不能默认照搬 OmniBox 的并发实现。

默认搜索预算 12 秒，单接口向宿主请求 2500 毫秒超时；预算耗尽后保留已完成的结果，日志记录成功、失败和未查询来源。同步模式在请求之间检查预算，无法强制中断正在执行的原生请求；部分旧宿主还会忽略 `timeout`，实际等待时间由客户端网络栈决定。一次搜索不保证遍历全部 176 个来源。缓存命中时会继续更快地查询后面的来源，也可缩小来源范围或增加预算。

列表和搜索缓存 60 秒、详情缓存 5 分钟，最多 100 条且约 400 万字符；初始化时清空。最终播放结果不单独长期缓存。JSON/XML 接口均支持，不依赖 OmniBox、Node、axios、cheerio 或在线 JS 库。

## 播放

明确的媒体地址返回 `parse:0`，HLS 同时返回 TVBox 的格式提示。普通网页返回 `parse:1`，由客户端嗅探或解析；嗅探是否成功取决于网页及客户端，不代表所有候选线路均已可播。OmniBox 的服务端刮削、弹幕、嗅探 SDK 未移入这个独立 TVBox 脚本。

验证了首页、分类分页、多源《老友记》搜索、详情、分集和播放返回结构。抽测 360 来源的《老友记》：主/子 HLS 清单及 16 字节密钥返回 200，媒体分片返回 206，AES 解密后的 TS 同步字节正常。另一个来源返回的 CDN 地址出现证书过期，需更换来源。未在实体电视上逐个验证全部接口和完整解码。

## 可选 ext

```json
{
  "timeoutMs": 2500,
  "searchBudgetMs": 12000,
  "sourceIds": ["360资源", "电影天堂"]
}
```

`sourceIds` 可用来源名称、内置 ID 的数组或逗号分隔文本；留空查询全部候选。名称有多个镜像地址时会同时选中，指定 ID 可精确选择一个。

只有已确认修复异步回调的宿主，才可增加 `"parallel":true,"concurrency":12`。并发数限制为 1–24，异步分支额外使用 JS 超时保留完成结果；超时不等于原生请求已经取消。默认配置未启用此选项。

列表方法返回 JSON 字符串，提供 `init/home/homeVod/category/search/detail/play` 七个旧版接口。入口和播放协议以仓库的[旧版开发文档](FONGMI_JS_LEGACY.md)为准。
